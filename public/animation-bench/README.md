# animation-bench blog figures

All candidate frames come from driving each model's `index.html` with the task's own `harbor_tasks/<task>/interaction.json` via `modules.scoring.capture.capture_scripted`, using the same drive variant (`candidate_drive`) that produced the score. Reference frames are `harbor_tasks/<task>/environment/src/input/screenshots/frame_*.png`. Strips show 5 evenly spaced frames per row (row label = model + overall score); GIFs use up to 16 frames at 480 px, 250 ms/frame, looping.

Generated with `make_strips.py` (this folder); `manifest.json` records the chosen trial per task/model. Captured frames are cached in `~/.cache/animation-bench-strips/` (override with `STRIP_CACHE`); delete to re-drive the pages.
