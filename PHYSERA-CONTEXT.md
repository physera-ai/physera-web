# History

## Simulations

For decades, modelling human behavior and complex systems reliably required enormous amounts of structured data.

### GPT-3 → Inflection Point

A lot of people tried to make models:

* Write like a specific person.
* Imitate a style.
* Reason through a task.
* Generalize from a few examples.

In-context learning.

### Key Insight

LLMs can learn behavioral patterns from very little context.

Examples → Model → New domain / New style / New behavior

Without traditional retraining.
